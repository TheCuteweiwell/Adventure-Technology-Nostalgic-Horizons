# Adventure-Technology-Nostalgic-Horizons
A modpack for Minecraft 1.7.10

关于ATNH\
这是个冒险与科技相结合的1.7.10整合包，主题为怀旧\
目前的主要玩法mod:\
科技: HBM:航天 通用机械 热力膨胀 工业时代2 EnderIO 应用能源2 BuildCraft等\
魔法: 神秘时代4 血魔法 植物魔法\
冒险: 虚无世界 寻找巧克力 古代战争 天境 糖果世界 龙之研究 潘马斯农场 极限末地生存等\
建筑: 小方块 更多家具 凿子 各种联动物品带来的装饰方块等

其他核心要素\
整合包含有与原版完全不同的地形，由超多生物群系和真实地形生成完美呈现\
由CraftTweaker和ModTweaker带来的部分配方魔改(正在施工)\
由Dynamic Surrounds带来的更加接近现实的环境音效\
回溯Minecraft 1.8+的实用物品\
还有针对Mod之间的优化和修复:修改部分冲突位置UI和修复严重崩溃\
大部分Mod已选用GTNH特供版Mod\
使用资源包加载形式避免任何违反Mojang ELUA和闭源Mod限制的许可\
还有更多

最低内存:4G\

ATNH安装方法:\
首先你必须有正版账号才能进行以下几步\
1.下载ATNH整合包文件和Prismlaucher，下载完后解压启动器(名字为prismlaucher)文件，千万不要解压ATNH文件\
2.下载jdk25，下载完后完后安装并重启电脑(建议默认路径安装)\
3.打开解压后的启动器文件夹，往下翻或搜索"prismlauncher.exe"打开启动器，登录你的微软账号\
4.进入启动器后点左上角的添加实例，点击导入，选择ATNH整合包的zip文件\
5.成功添加实例后这样做:单击ATNH实例图标->右边点击编辑->设置->Java->勾选Java安装和内存->检测Java->选择Java25.x.x->最大内存设为100000MiB(可关闭内存警告)\
6.保存后启动游戏，初次启动会下载各种依赖(Mojang.com下载游戏本体，lwjgl3ify下载lwjgl3的依赖，再新弹出窗口下falsepatternlib的依赖，最后进入游戏加载后会卡在Iguanas Tinker Tweaks数分钟，这部分根据你的电脑性能决定)，网不好下载速度会比较慢，有必要可以挂梯子
